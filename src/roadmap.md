# Roadmap

Features that are done and planned for authbox.

## Done

- [x] Async architecture
- [x] JWT authentication
- [x] Refresh token rotation
- [x] Refresh token revocation
- [x] Session revocation (password reset, password change, account deletion)
- [x] Logout from all devices
- [x] Email verification
- [x] Password reset flow
- [x] Change password
- [x] Account deletion
- [x] One-time token support with atomic claim
- [x] User cache with metrics (`authbox-cache`)
- [x] Resend, SendGrid and SMTP email providers
- [x] Pluggable storage backends
- [x] Custom registration DTO support
- [x] Works with any web framework
- [x] Middleware support (use `is_token_valid()`)
- [x] Actix Web example
